# Gyroid Lamp Studio

Веб-прототип параметрического генератора настольного светильника. После публикации открывается по обычной ссылке GitHub Pages.

## Использование
Откройте сайт в современном браузере. 3D-просмотр поддерживает мышь и сенсорное управление. Настройте абажур, основание, байонет и посадку светового модуля; экспортируйте STL или JSON.

## Ограничения прототипа
- Three.js загружается с CDN, поэтому для работы нужен интернет.
- Геометрия Gyroid и механика байонета — экспериментальный прототип, не готовая производственная CAD-модель.
- Посадки Bambu Lab LED Kit 001 и E27 необходимо измерять по конкретным компонентам и калибровать.
- Перед печатью проверяйте STL в Bambu Studio/OrcaSlicer: manifold, толщины, прочность, нависания и точность сопряжений.
- Используйте только LED-модули и соблюдайте требования производителя электрики.
